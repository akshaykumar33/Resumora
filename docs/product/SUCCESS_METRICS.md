# Success Metrics & North Star

## North Star Metric

> **Total Recovered User Intents** (Count of user actions restored after unexpected interruptions).

## Key Supporting Metrics

1. **Recovery Success Rate**: > 99.9% of interrupted sessions offer complete state recovery.
2. **Time to Resume (TTR)**: < 150ms from application load to full restored interactive state.
3. **Multi-Tenant Isolation Zero-Leak Invariant**: 0 reported incidents of cross-tenant or cross-user state exposure.
4. **Developer Adoption**: < 10 lines of code to enable workflow recovery on any multi-step form.
